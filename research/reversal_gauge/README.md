# Reversal Gauge

Scores mid-leg "freeze" events — a leg that has run >= 8pt and then given
back >= 25% of its MFE — for p(resume): does the leg reclaim its extreme,
or is the giveback the start of the reversal? Logistic combiner over
causal leg-shape / level-memory / day-shape / clock features.

Run everything from the repo root with
`/home/moi/miniforge3/envs/bayesian/bin/python`.

## Layout

| Path | What it is |
|---|---|
| `builders/extract_freeze_events.py` | Event extractor. 5s-close zigzag (8.0pt reversal), RTH 09:30–15:30 ET, one event max per leg at the first bar where giveback_frac >= 0.25 with mfe_pt >= 8.0. Labels forward max 45min: `label_resume=1` if price exceeds peak by >= 0.5pt before retention drops below 0.50; unresolved rows kept with `label_resolved=0`. All features strictly causal (bars <= event ts; zigzag legs active only from causal confirmation). Day 2024_09_16 excluded (contaminated). Writes `events.parquet`. |
| `pipeline/fit_combiner.py` | Fits the combiner on `label_resolved==1` rows. Features (fixed order): giveback_frac, pace_pts_s, spike_score, repoke, worn_touches, is_flushV, clock_sin, clock_cos. Standardized logistic regression (sklearn, C=1.0, lbfgs), GroupKFold(5) by day. Reports cv AUC, 10-bin reliability table, and baselines (giveback_frac alone; constant). Writes `coeffs.json` + `reports/reversal_gauge_v0.md`. |
| `tools/gauge.py` | Pure scorer. `load_coeffs()` (cached), `p_resume(feat) -> (p, drivers)` with mean-fallback for missing features, `format_gauge(p, drivers, n_top=3)` -> one-line string like `p(resume) 62% \| +pace +flushV -giveback`. No I/O besides reading `coeffs.json`. Has a `__main__` smoke test. |
| `events.parquet` | Extractor output: one row per freeze event (day, ts, dir, anchor/peak px, mfe, giveback, pace, spike, repoke, worn_touches, day_class, clock_bucket, labels). Generated — not committed. |
| `coeffs.json` | Fitted combiner: features/means/stds/coef/intercept + cv AUC, N, base rate. Generated by `fit_combiner.py` — gauge.py's only input. |
| `reports/reversal_gauge_v0.md` | Full fit report: N, base rate, fold AUCs, reliability table, coefficients by \|coef\|, baselines, verdict vs the program's 0.57 AUC ceiling. |

## How to run

```bash
# 1. Extract freeze events (reads DATA/ATLAS/5s/, writes events.parquet)
/home/moi/miniforge3/envs/bayesian/bin/python research/reversal_gauge/builders/extract_freeze_events.py

# 2. Fit the combiner (writes coeffs.json + reports/reversal_gauge_v0.md)
/home/moi/miniforge3/envs/bayesian/bin/python research/reversal_gauge/pipeline/fit_combiner.py

# 3. Score an event / smoke test
/home/moi/miniforge3/envs/bayesian/bin/python research/reversal_gauge/tools/gauge.py
```

## Data

- Input bars: `DATA/ATLAS/5s/YYYY_MM_DD.parquet` (per-day; columns
  `timestamp` [epoch s, UTC], `open`, `high`, `low`, `close`, `volume`).
  604 day files. ET = `tz_convert('America/New_York')`. MNQ tick 0.25.
- Day `2024_09_16` is excluded from extraction (live/contaminated).
- Generated artifacts (`events.parquet`, `coeffs.json`) live in this
  folder and are reproducible from the two commands above.
