# Enhancing Productivity with Keyboard Hot Key Shortcuts in the NinjaTrader Desktop

By
NinjaTrader Team

February 05, 2025

Keyboard Hot Key shortcuts are a powerful feature in the NinjaTrader Desktop [platform](/trading-platform/), enabling users to navigate the platform, execute trades, and perform critical tasks with speed and efficiency. By mastering these shortcuts, traders can focus more on market analysis and decision-making, rather than navigating menus and interfaces.

Let’s explore the advantages of using keyboard shortcuts, NinjaTrader’s default shortcuts, and how to customize shortcuts to fit your specific trading workflows.

## Advantages of Using Shortcuts

Using keyboard shortcuts on the NinjaTrader platform offers several benefits:

* **Increased****s****peed:**Perform tasks quickly without navigating through menus.

* **Enhanced****f****ocus:**Stay engaged with charts and data instead of searching for commands.

* **Customization:** Tailor shortcuts to match individual trading styles and preferences.

* **Reduced****e****rrors:**Eliminate the chance of misclicking in high-pressure situations.

## Default Keyboard Shortcuts

NinjaTrader comes equipped with a set of default keyboard shortcuts designed to simplify common tasks and [order entry](/learn/how-to-trade-futures/place-a-futures-order/). You can view many shortcuts in the right-click context menu on most windows and in toolbar dropdowns located at the top of the chart. To access the list of customizable keyboard Hot Keys from the Control Center, click Tools à Hot Keys (Figure 1).  

## Hot Key Editor*Figure**1: Hot Key**e**ditor**d**ialog from the Control Panel*Customizing Keyboard Shortcuts

NinjaTrader gives you flexibility to create and modify keyboard shortcuts, so you can optimize the platform for your unique needs. Here’s a step-by-step guide to customizing shortcuts: 

### Accessing the Hot Key Window

1. Navigate to the main Control Center.

2. Click on Tools in the menu bar.

3. Select the Hot Key window from the dropdown.

## Understanding the Layout

The Hotkey window is divided into categories, such as Chart, Order Entry, and General. Each category lists the actions and their associated shortcuts.

### Modifying an Existing Shortcut

1. Locate the desired action in the list.

2. Click on the shortcut field next to the action.

3. Press the new key combination you want to assign; you can also reassign existing shortcuts.

4. Ensure there are no conflicts with other shortcuts; the dialog will autodetect conflicts.

* Add a new shortcut: If an action does not have a shortcut, click the empty field next to it, and press the desired key combination.

* Remove or reassign a shortcut: To remove a shortcut, select the action, clear the existing Hot Key combination, and record a new keyboard Hot Key sequence.

* Save and test changes: Click OK to save your changes and test your new shortcuts to ensure they work as intended.

## Defining Your Own Custom Platform Shortcuts

You can select from several Hot Key categories on the right side of the Hot Keys dialog. Below are some sample Hot Keys combinations for general platform navigation and common tasks. There are also some preassigned platform Hot Keys for general navigation and common trading tasks. To use them, remember to hold down Ctrl, Alt, or Shift, and then press the action key.

**Global New**

* Open new chart = Ctrl + Shift + N

* Open new order entry ticket = Ctrl + Shift + T

* Open new SuperDOM = Ctrl + Shift + D

**Global Orders**

* Cancel all orders = Alt + Shift + Z

* Flatten everything = Alt + Shift + F

**Global Workspaces**

* Save workspace = Shift + F4

* Switch between workspaces = Shift + F3

## Best Practices for Shortcut Customization

* **Keep****i****t****s****imple:**Use intuitive combinations that are easy to remember.

* **Avoid****c****onflicts:** Check for overlapping shortcuts to prevent unintended actions.

* **Test****b****efore****t****rading:**Ensure the shortcuts function as expected in a simulated environment before using them in live trading.

* **Document****y****our****c****hanges:**Maintain a record of custom shortcuts for future reference or troubleshooting.

### Knowing When Hot Keys Are Active

After making changes in the Hot Key window, you may see this message dialog below (Figure 3). This means that a Hot Key may be inactive unless it’s relevant to the current selected window. For example, a charting Hot Key will not work if the selected window is the SuperDOM or Market Analyzer—it will work only in charting. 

![Hot Key Warning Dialog](/getmedia/990a4952-a897-48e3-95f3-809a8b0efd82/HK3.png)*Figure 3: Hot Key warning dialog that hot keys are inactive if the appropriate window is not selected.*
