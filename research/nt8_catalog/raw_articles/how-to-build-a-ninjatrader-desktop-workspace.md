# Platforms Unleashed: Building a NinjaTrader Desktop Workspace

By
NinjaTrader Team

July 14, 2025

Creating a powerful, personalized workspace is one of the first steps in making the NinjaTrader Desktop platform your own. Whether you're trading on a single laptop screen or managing multiple monitors, the platform's modular design allows you to create an efficient layout that supports your strategy and trading flow.

Let’s break down the core components and walk through how to build a workspace from scratch.

## Start with the control panel

When you first launch the NinjaTrader Desktop, the Control Panel appears automatically. This is the command center of your workspace. From here, you can:

* Connect to a data provider
* Access account information
* Launch key features like charts, SuperDOMs, and analyzers

To create a new workspace, go to the top menu, select Workspaces, then click New. Give your workspace a name—something intuitive, like “Simple Start”—and you’re ready to begin adding components.

![NinjaTrader desktop with the 'New' dropdown menu open, and the 'Chart' option highlighted. A candlestick chart of ES SEP25 is visible in the background.](/getmedia/452f8d7b-7428-445d-8c28-631ebd414a34/Building-a-NinjaTrader-Desktop-Workspace-New-Workspace.jpg)

## Add a Market Analyzer for real-time quotes

The [Market Analyzer](/futures/blogs/how-to-use-the-ninjatrader-market-analyzer-your-personal-real-time-quote-board/) is your customizable quote board and more. To add it to your NinjaTrader Desktop workspace:

1. Click New > Market Analyzer
2. Right-click to add instruments (e.g., ES, MNQ, RTY, CL, 6E, GC)
3. Use smart search to find markets by symbol or name
4. Organize your instruments using Label Rows (e.g., “Stock Index Futures,” “Energy Futures”)

![NinjaTrader application showing the 'New' menu dropdown with 'Market Analyzer' highlighted, over a desktop background with NinjaTrader shortcut icon visible.](/getmedia/7874dede-ba25-48f0-bbfa-e8c7a6575f9d/Building-a-NinjaTrader-Desktop-Workspace-New-Market-Analyzer.jpg)

You can further personalize the Market Analyzer by color-coding label rows and adjusting visual preferences like highlight colors. This modular tool can help you stay on top of real-time price action across multiple asset classes.

## Create your first chart in your NinjaTrader Desktop Workspace

Charts are central to [technical analysis](/learn/technical-analysis/). Here’s how to launch one:

1. Click New > Chart
2. Choose your instrument (e.g., gold futures)
3. Select a time interval (e.g., 10-minute chart)
4. Set how many days of data to display
5. Pick your chart style (e.g., candlestick)

![NinjaTrader desktop with the 'New' dropdown menu open, and the 'Chart' option highlighted. A candlestick chart of ES SEP25 is visible in the background.](/getmedia/06e0b52f-ea84-4603-9c61-cadedcbe48fc/Building-a-NinjaTrader-Desktop-Workspace-New-Chart.jpg)

Once your chart is open, customize it further:

![NinjaTrader chart window for the ES SEP25 contract displaying candlestick data with the right-click context menu open. Menu items include indicators, strategies, drawing tools, and options for reloading and printing the chart.](/getmedia/359cf567-205a-4d49-bd2d-10143b0191fd/Building-a-NinjaTrader-Desktop-Workspace-Chart-Controls.jpg)

* Add indicators (e.g., Bollinger Bands, RSI)
* Adjust line colors, panel layout, and data calculation frequency
* Duplicate the chart into new tabs or windows to create multichart views

This flexibility can make it easier to monitor multiple timeframes or markets simultaneously.

## Insert the SuperDOM for fast order entry

The [NinjaTrader SuperDOM (depth of market)](/futures/blogs/intro-to-the-ninjatrader-desktop-superdom/) window allows for precise, fast-paced order execution. To add it:

1. Click New > SuperDOM
2. Choose either the static or dynamic version
3. Select a simulated or live trading account

![](/getmedia/65ce41a4-ec26-4e1e-9c49-6e644ee74fa1/Building-a-NinjaTrader-Desktop-Workspace-New-SuperDOM.jpg)

Position the SuperDOM wherever it fits your layout best. You can run multiple DOMs across different instruments for active trading in real time.

## Link your windows for seamless navigation

One of the NinjaTrader Desktop workspace’s most efficient features is instrument linking. By color-coding your Market Analyzer, charts, and SuperDOM with the same instrument link (e.g., orange), a single click in the Market Analyzer updates all linked windows instantly.

This allows you to cycle through markets quickly without changing each chart or ladder manually.

## Add time and sales to complete your view

For tick-by-tick insight, add a Time and Sales window:

1. Click New > Time and Sales
2. Link it to the rest of your workspace with the same instrument color

![NinjaTrader desktop interface showing the expanded 'New' dropdown menu with 'T & S' (Time & Sales) highlighted, alongside an active candlestick chart of the ES SEP25 contract.](/getmedia/3584ff1d-95e6-4698-9a05-847642063560/Building-a-NinjaTrader-Desktop-Workspace-Add-Time-and-Sales.jpg)

This tool can help you track order flow and volume as it happens, which can be especially helpful for short-term strategies.

## Save your workspace and log off

Once you’ve set up your ideal layout, save it:

* Click Workspaces > Save
* When you’re done trading, close the workspace via the Control Panel X, not via individual windows

This ensures everything will reopen just as you left it during your next session.

![](/getmedia/20cfa7aa-89ba-45bd-b743-cd8ac26badc1/Building-a-NinjaTrader-Desktop-Workspace-Save-Workspace.jpg)

## Use workspaces to match your trading goals

The NinjaTrader Desktop supports multiple workspaces, each tailored to different needs. For example:

* Dedicated charting workspace for presession analysis
* Workspace focused on energy futures
* Real-time execution layout for day trading

Toggling between them is simple and quick and can help keep your trading organized and efficient.

![](/NT/media/images/Lifestyles%20for%20Primary%20Pages/contract-specs-hero.png)

## Empower your trading experience

Building your NinjaTrader Desktop workspace is more than just adding charts and tools—it's about creating a personalized environment that fits your strategy and style. Whether you're just starting out or fine-tuning a multimonitor command center, NinjaTrader’s intuitive design puts you in control.
