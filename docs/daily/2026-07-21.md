# 2026-07-21 — Memory FTS auto-freshness hook

## Context
The knowledge-memory `.db` augmentation (`tools/memory_loop/`, doc 123 full-corpus
FTS mirror) was complete but **manual**: nothing rebuilt `docs/memory/memory.db`, so
it had gone 3 days / 38 markdown files stale (built 2026-07-18, verified this session).
The "migrate to .db" ask was really "close the freshness loop," not make the DB
authoritative — markdown stays the source of truth; the DB stays STRICTLY DERIVED.
(A separate collision cleared up first: `examples/SPEC_ARCH_LOCK_MACRO_MEMORY.md` is
the RL model's `MacroBank` feature-bank, an unrelated "memory" — see note below.)

## What changed
1. **New hook guard** `tools/memory_loop/rebuild_on_write.sh` — a PostToolUse guard
   that reads the tool-call JSON on stdin, and ONLY when a Write/Edit touches a memory
   SOURCE (`docs/memory/` or `docs/daily/`) runs `build_memory_db.py --quiet`. Every
   other edit pays just a jq+grep. Self-locates the repo root; swallows all errors so
   it can never break a turn. Uses `python3` (Linux/WSL env — we migrated to Linux to
   run Mamba; the README's `python3.11` is the legacy Windows training env).
2. **Wired** `.claude/settings.local.json` → `hooks.PostToolUse` matcher `"Write|Edit"`
   → `bash tools/memory_loop/rebuild_on_write.sh`. Machine-scoped (local) on purpose.
3. **Refreshed the DB** — manual rebuild picked up the 3 missing days: 3037 → 3224 rows.

## Files
- `tools/memory_loop/rebuild_on_write.sh` (new)
- `.claude/settings.local.json` (added `hooks` block)
- `docs/memory/memory.db` (regenerated; gitignored)

## What to look for next run
- **DB freshness**: after any `docs/memory/` or `docs/daily/` edit, `memory.db` mtime
  should bump automatically. If not, open `/hooks` once (or restart) so the settings
  watcher reloads the newly-added hook.
- **Flagged, not fixed**: `build_memory_db.py` now reports **2 code parse-failures**
  (was 0 on 2026-07-18) — two Python modules no longer AST-parse under Python 3.14;
  and the build emits `\s` `SyntaxWarning`s (regex strings not raw). Both cosmetic;
  candidates for a follow-up cleanup.

## Expected impact on metrics
None — infra only. No trading-path code touched. Blast radius = the derived FTS index
(gitignored, rebuildable in ~2.5s).
