# 2026-07-07 — Seq trainer 50-epoch autonomous run + exit-action bug

Continuation of the mamba perf/training work (see 2026-07-05.md, 2026-07-06).
Full report: `research/mamba_zigzag_baseline/reports/SEQ_TRAINER_50EPOCH_2026-07-07.md`.

## What happened (autonomous, user asleep)
User suspected the trainer was buggy and asked to run 50 epochs + monitor.
Ran a short diagnostic first → **found the bug**.

- **BUG (exit-action mapping)**: exit head samples Bernoulli {0=hold,1=exit},
  raw int passed to env.step, but env closes a LONG only on action 2/3 and a
  SHORT only on 1/3 → a long receiving exit-intent 1 no-ops and holds until
  the 15:55 guard rail. Symptom: 1 trade/day, 16,459-bar hold. FIX: map
  exit-intent → SCRATCH(3), keep policy action {0,1} for the loss. Committed.
  Same latent bug in `train_mamba_rl.py` (per-bar) — flagged, left as-is.
- **Launch recovery**: first nohup launch sent stdout to a dead pipe (no
  file) → process blocked mid-epoch when the pipe buffer filled (22 min, 0
  checkpoints). Relaunched via `tools/launch_seq_train.sh` (setsid + internal
  exec-redirect). Committed the launcher.

## 50-epoch result
- 3.9 h, 285 bars/s, 4.01M bars, **no crash/NaN**, checkpoints every epoch.
- Windowed mean reward: ep0-9 -9767 → ep10-19 -3772 → **ep20-29 -3402 (peak)**
  → ep30-39 -4191 → ep40-49 -3832. Best single epoch **25 (-2558)**.
- **Behavior overshoot**: overtrading (9630 trades/5d, 7-bar holds, ep0) →
  moderate (52 trades, ep29) → over-HOLDING (9-19 trades, 4000-9000-bar =
  5-12h holds, -$38 to -$81/trade, ep47-49).
- **Diagnosis**: regression correlates with the entropy schedule flooring at
  epoch 25 (0.01→0.001 over first 50%); exploration dies → policy exploits a
  degenerate long-hold local optimum.

## Verdict
Mechanically sound + learns (20× to the ep25 peak), but converges
non-profitable (best -2558/5d shaped reward) and the back half regresses to
over-holding. **Best checkpoint = epoch 25.**
